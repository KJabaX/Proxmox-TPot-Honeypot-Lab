# Investigation Cases

This directory contains selected case studies derived from honeypot telemetry.

The source IP addresses are retained as technical indicators because they are part of the observed network evidence. An IP address identifies an observed network source at a point in time; it does **not** by itself establish the identity, intent, or ownership of a human actor.

Public case notes intentionally exclude raw log exports, packet captures, evidence archives, captured binaries, private infrastructure addressing, and plaintext honeypot credentials. Where a credential value matters to the analysis, the public version records the event while redacting the plaintext value.

The detailed collection and analysis process is documented under [`../T-Pot-Attack-Analysis/`](../T-Pot-Attack-Analysis/).
